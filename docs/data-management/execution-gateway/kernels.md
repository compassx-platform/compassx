# Remote Compute Kernels

CompassX packages custom kernel environments tailored for data science and AI workloads.

---

## Supported Kernel Specs

| Kernel Spec | Language / Runtime | Included Libraries |
| :--- | :--- | :--- |
| **Python 3.11 Standard** | Python | NumPy, Pandas, DuckDB, SQLAlchemy, Polars |
| **Python ML / AI** | Python | PyTorch, Hugging Face Transformers, pgvector, LangChain |
| **DuckDB Analytics** | SQL / Python | In-memory DuckDB analytical engine |
