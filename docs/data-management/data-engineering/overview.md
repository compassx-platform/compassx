# Data Engineering Overview

CompassX provides modern, cloud-native data processing pipelines for high-performance analytical queries and ETL transformations.

---

## Capabilities

- **Vectorized Query Execution**: In-memory analytical query processing powered by DuckDB.
- **Direct Object Storage Integration**: Query Parquet, CSV, and Arrow files directly from S3/MinIO.
- **Unified Catalog**: Central metadata and schema management across data sources.
